## Flower Password

[Flower Password ](https://github.com/kenmick/FlowerPassword)is an open-source software that helps users automatically generate passwords. Users only need to remember one master password to generate passwords for different websites.
Flower Password calculates and generates passwords through a combination of the master password and a distinguishing code (Site Keywords).
Based on HMAC, it performs real-time frontend calculations without requiring backend storage, making it more secure.
It provides cross-platform support, including [Website](https://flowerpassword.com/), Mac, Windows, iOS, Android, [Chrome](https://github.com/FlowerPassword/chrome-extension), and more.
